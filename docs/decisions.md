# 實作裁定紀錄

本檔記錄 spec_v1（v1.3）定稿後，Hector 於實作期間對規格疑義所作的裁定。實作以規格書為準，本檔所列項目優先於規格書相對應文字。

## 2026-11-25（Asia/Taipei）

| 編號 | 議題 | 裁定 |
| :--- | :--- | :--- |
| 連線 | M2 API 實測環境 | 採 (c)：repo 建立後另加一支 `workflow_dispatch` 驗證 workflow，在 GitHub runner 上實測 API（同意在 8.1 結構外多此檔案）。 |
| Q1 | 週 K 根數需求 | W20MA[t]、W20MA[t-1]、前 20 週均量三者視窗重疊，實需 21 根週 K（S3／S4 需 27 根）。第 9 節「均量樣本較少」警示門檻由 41 改為 **21**。 |
| Q2 | 週 K 圖 W20MA 線覆蓋 | 回溯週數由 45 改為約 **60 週**（`config.yaml` `data_source.lookback_weeks: 60`），使 40 週圖全程有 W20MA 線。 |
| Q3 | 爆量倍數設定 | 頁 2 爆量門檻跟 `screening.volume_spike_ratio` 走；S1 固定 1.5／2.0 配分；驗收用預設 1.5。 |
| Q4 | TPEx 三大法人欄位 | 規格未列欄位名，M2 抓實際回應回報後再實作；之前上櫃股法人參考欄顯示空值。 |
| Q5 | S3～S6 細節 | S3：「突破 26 週高點」視同切線突破得 10 分；切線不合格時改試前一組高點，無合格組則放棄切線（角度判準已由下方「S3 角度」裁定取代）。S4：採 `L2 >= L1 × 0.99`，擺盪點左右鄰週須落在 t-1 以內。S5：僅計本週實際發生之穿越，以每日暫定 W20MA（前 19 週收盤＋當日收盤）比較。S6：同業檔數 N 含自身；龍頭取同業股本 > 20 億普通股市值前 2 名。 |
| Q6 | FinMind 斷線時產業別 | 顯示官方產業代碼。 |
| Q7 | 公開資料來源 | 網頁加註資料來源（臺灣證券交易所、證券櫃檯買賣中心）；資料使用條款由 Hector 另行查證。 |
| 小問題 | 規格細節 | `latest.json` 重複鍵只輸出一次；D20MA 一律用還原價；頁 1／出場的 t-1 等號條件照字面；停牌日不計入有效日；`is_week_settled` 依「as_of_date 之後本週平日均已過且無資料或為休市日」判定。 |
| S3 角度 | 切線陡度判準 | 已查證原文（CMoney 2025-10-22 署名文、CMoney 投資小學堂）：趨勢線「不能太陡（代表盤整時間太短），沒有固定的斜率，可以以 40 度為基準」，未定義量法，屬看圖目測參考，**不採**每週 % 換算角度。定案：(1) 主定義為切線兩擺盪點最少間隔 Δt ≥ `screening.trendline_min_pivot_gap_weeks`（預設 8 週，回測掃 8～13），不足不給切線分；(2) 可選「切線偏陡」警示：r = (lnP1 − lnP2) / Δt 超過 `screening.trendline_steep_warning_log_rate` 即標示，不影響得分，預設 `null`（關閉），門檻由回測校正；(3) S3 仍為加分項，不硬剔除，週 K 圖照常供目視；(4) 移除 `trendline_angle_norm_pct_per_week`。 |
| S3 補充 | 參考欄位、選點順序、警示開關 | (1) `trendline_max_angle_deg: 40` 保留，**僅原文參考，不參與計算**。(2) 最近一組下降高點間隔不足 `trendline_min_pivot_gap_weeks` 時，依序改試更早的高點組合，找到第一組間隔 ≥ 門檻且 H2 < H1 的合格組即用以畫切線；全部不合格才不給切線分。(3) 偏陡警示維持單一參數 `trendline_steep_warning_log_rate`，`null` 即關閉，不另設開關。 |
| 驗證 | M1 自加規則 | 保留：`lookback_weeks` 下限 27 週；定案值被改即報錯；workflow 輸入環境變數命名 `SW20_*`。 |
| 套件 | requirements.txt | 增列 `tzdata`、`pytest`。 |
| Repo | 推送節奏 | 每個里程碑完成即推送一次至 `bstestim-dev/stock-w20`。 |
